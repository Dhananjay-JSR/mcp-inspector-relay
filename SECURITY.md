# Security Policy

## Reporting a vulnerability

Please report security issues privately by opening a
[security advisory](https://github.com/Dhananjay-JSR/mcp-inspector-relay/security/advisories/new)
rather than a public issue.

Include reproduction steps, the affected endpoint, and the impact. You can expect
an initial response within a few days.

## Scope

The relay proxies user-supplied URLs, so SSRF and origin-allowlist bypasses are
in scope. Reports about upstream MCP servers or the VS Code extension belong in
their respective repositories.
